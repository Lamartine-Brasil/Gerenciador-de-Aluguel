# STATUS DO PROJETO - Sistema de Gerenciamento de Aluguéis

Este arquivo reflete o estado ATUAL do projeto (não é um histórico de fases nem um changelog
por data). Ao implementar algo novo, atualize a seção correspondente aqui e em README.md.

## Mapa das abas do sistema

A barra de navegação tem 11 abas, agrupadas visualmente (divisores sutis) em 5 blocos:

  Visão Geral │ Cadastros          │ Financeiro                  │ Análises                   │ Sistema
  Dashboard   │ Imóveis, Contratos │ Atrasos, Histórico, Despesas│ Gráficos, Relatórios,       │ Auditoria,
              │                    │                             │ Calendário                  │ Config.

As seções abaixo seguem essa mesma ordem. "Pagamentos" não é uma aba — é o modal de registrar
pagamento, acessado de dentro de Contratos ou Atrasos — por isso aparece logo depois de
Contratos.

- [x] Permanece logado ao trocar de aba/página ou reabrir o navegador

- [x] Múltiplos usuários administradores, todos com as mesmas permissões (acesso total).

- [x] Alerta de dívidas vencendo nos próximos 5 dias

### Cadastros — Imóveis
- [x] Aba dedicada de cadastro de imóveis (descrição livre, ex: "Apartamento 302 - Rua

- [x] Remover um imóvel da lista não afeta contratos que já usam aquela descrição

### Cadastros — Contratos
- [x] Modelo de dados: um **contrato** (imóvel + inquilino, dados compartilhados) guarda
      dentro de si uma lista de **dívidas** (uma por mês/ciclo de cobrança: vencimento,
      valores, se foi paga, pagamentos) — em vez de um contrato = um vencimento só. Um
      contrato antigo lançado retroativamente vira 1 contrato com N dívidas em aberto,
      não N contratos separados (bug real relatado e corrigido nessa reestruturação).
      Migração automática e transparente do formato antigo, sem perder nenhum dado,
      testada com dados reais de produção antes de entrar no ar
- [x] Listar, criar, editar, excluir — 1 card por contrato, com a lista de dívidas
      daquele contrato dentro do card (cada dívida com seu próprio status, valores e
      ações de pagar/editar/excluir)
- [x] Número sequencial único gerado automaticamente na criação (`#1`, `#2`...), exibido
      no card do contrato e nos modais de pagamento/histórico, usado só para identificar
      o contrato (não tem relação com o `id` interno). Nunca se repete, mesmo depois de
      excluir contratos. Também entra na busca (buscar por "#12" encontra o contrato 12).
      Contratos de instalações antigas (sem número) recebem um automaticamente na
      primeira vez que os dados são carregados, na ordem de criação
- [x] Campos do contrato (compartilhados entre as dívidas): imóvel, inquilino, quem
      recebe (padrão), data de início, dia de pagamento, anexo do contrato assinado,
      caução (opcional)
- [x] Campos de cada dívida: vencimento, aluguel, desconto, juros, multa, condomínio,
      valor em atraso, observação — total calculado automaticamente
- [x] Busca por inquilino, imóvel ou número do contrato (`#12`); filtro por ano, mês e
      status (um contrato aparece se pelo menos uma das suas dívidas bater com o filtro)
- [x] Ao criar um contrato novo, os campos Juros e Multa são digitados em percentual
      (%) do aluguel, não mais em R$ — vêm pré-preenchidos com a taxa de juros/multa
      configurada em Configurações (a mesma usada no cálculo automático de atraso) e
      são convertidos para R$ ao salvar a dívida. Na edição de uma dívida já existente,
      continuam sendo digitados direto em R$ (valor fixo daquele mês, sem recalcular)
- [x] Criação de contrato pede "Data de início do contrato" e "Dia de pagamento" (1-31)
      — o primeiro vencimento é calculado a partir desses dois campos (com ajuste
      automático se o dia não existir naquele mês, ex: dia 31 em fevereiro vira o
      último dia do mês)
- [x] Lançamento retroativo de contratos antigos: se a data de início informada já
      passou, o sistema gera automaticamente uma dívida para cada mês seguinte (mesmo
      dia de pagamento, com ajuste automático em meses menores) até o mês atual, todas
      dentro do MESMO contrato — evita ter que cadastrar manualmente cada mês em atraso.
      Pede confirmação antes, mostrando quantas dívidas serão criadas. O "valor em
      atraso já existente" só é aplicado na dívida mais recente gerada, não em todas
- [x] Botão "Atualizar dívidas" em cada contrato: gera as dívidas que faltam entre a
      última já existente e o mês atual, usando os valores padrão atuais do contrato —
      é assim que um contrato "cresce" mês a mês conforme o tempo passa. Botão global no
      topo do sistema faz isso de uma vez para todos os contratos, e a mesma checagem
      roda sozinha, silenciosamente, toda vez que o sistema é aberto (login) — garante
      que as dívidas ficam sempre em dia sem depender de cron no servidor nem de o
      usuário lembrar de clicar em nada
- [x] Editar contrato (dados compartilhados: imóvel, inquilino, quem recebe, caução,
      corretor, anexo) é uma tela separada de editar uma dívida específica (vencimento e
      valores daquele mês)
- [x] Lista paginada (20 contratos por página), com botões Anterior/Próxima e indicador
      de página. A página volta para 1 automaticamente ao mudar busca ou filtros
- [x] Anexar o contrato assinado (PDF, JPG ou PNG, até 15MB) — um por contrato (não por
      dívida), pela tela "Editar contrato". Arquivos ficam em `contratos/` (pasta
      protegida por `.htaccess`, como `data/`), renomeados automaticamente no servidor
      para `nomedoinquilino-imovel-idcurto.ext` (removendo acentos e caracteres
      especiais). Só é possível anexar em um contrato já existente
- [x] Reajustar valor: botão "Reajustar" no contrato lança um novo valor de aluguel —
      atualiza o valor padrão do contrato (usado em dívidas futuras) e também todas as
      dívidas ainda não pagas; dívidas já pagas mantêm o valor histórico. Fica
      registrado na Auditoria com o valor antigo, o novo e quantas dívidas foram
      atualizadas. Qualquer usuário administrador pode reajustar (decisão consciente:
      sem restrição de usuário específico)
- [x] Excluir contrato apaga o contrato inteiro e todas as suas dívidas (com aviso
      mostrando quantas); excluir uma dívida específica remove só aquele mês, mantendo
      o resto do contrato
- [x] Corretor (opcional, por contrato): nome (escolhido da lista de "Pessoas"
      cadastrada em Configurações, para não digitar toda vez) + percentual (padrão
      configurável em Configurações, ex: 5%). O valor do corretor é só um cálculo
      informativo mostrado em cada dívida (aluguel da dívida × percentual) — mesma
      lógica do condomínio: faz parte do que passa pela mão do proprietário, mas não
      conta como receita dele. Não é somado ao total cobrado do inquilino, não muda
      nenhum vencimento, e não tem rastreio de pagamento separado. O campo de percentual
      só aparece quando um corretor é de fato escolhido (com "Nenhum" selecionado, a
      comissão simplesmente não existe); ao trocar de "Nenhum" para um corretor, o
      percentual volta ao padrão configurado
- [x] Caução (opcional, por contrato): valor digitado na criação ou em "Editar
      contrato". É só uma anotação informativa exibida no card do contrato — nunca
      soma em nenhum total, dívida, atraso ou relatório, já que em teoria é devolvida
      ao inquilino no final
- [x] Encerrar contrato: botão "Encerrar contrato" marca o contrato como encerrado (com
      confirmação) — diferente de excluir, NÃO apaga nada: todas as dívidas e o
      histórico de pagamentos continuam existindo e visíveis normalmente, só faz o
      sistema parar de gerar novas dívidas mensais automaticamente (nem pelo botão
      "Atualizar dívidas" nem pela atualização automática de login). Pensado para
      quando um inquilino deixa o imóvel, mantendo o histórico do contrato. Mostra um
      badge "Encerrado" e a data no card; pode ser revertido a qualquer momento pelo
      botão "Reabrir contrato"

### Cadastros — Pagamentos (modal, acessado de Contratos/Atrasos)
- [x] Modal "Registrar pagamento" (por dívida) com: data, valor pago, desconto, forma
      de pagamento, quem recebeu, observação
- [x] Valor sugerido automaticamente = total da dívida + atraso atual (juros/multa)
- [x] Campo "Desconto (R$)": ao digitar, recalcula o valor pago automaticamente
      (total + atraso - desconto); o campo valor pago continua editável manualmente depois
- [x] Campo "Forma de pagamento": seleção obrigatória entre Dinheiro e Pix
- [x] Campo "Quem recebeu": seletor da lista de "Pessoas" cadastrada em Configurações

      contrato — evita digitar toda vez. Não é mais obrigatório
- [x] Ao confirmar, marca a dívida como paga, registra a data do pagamento e zera o
      atraso base daquela dívida (as outras dívidas do mesmo contrato não são afetadas)

### Financeiro — Histórico de pagamentos
- [x] Aba geral com todos os pagamentos de todas as dívidas de todos os contratos,
      filtrável por contrato
- [x] Modal de histórico por contrato (acessível pelo botão "Histórico"), somando os
      pagamentos de todas as dívidas daquele contrato, mostrando de qual dívida

- [x] Exibição de desconto e forma de pagamento em cada registro do histórico
- [x] Exportação CSV do histórico de um contrato específico (inclui desconto, forma de

- [x] "Valor líquido" exibido ao lado do "Valor pago" (na aba geral e no modal por
