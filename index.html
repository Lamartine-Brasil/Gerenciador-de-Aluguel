Acessos abertos

Se você entrou no sistema num computador que não é seu, ou acha que alguém pode estar usando seu acesso, desconecte todo mundo de uma vez: quem estiver conectado em outro computador ou navegador precisa entrar de novo com usuário e senha. Você continua conectado aqui.

Contas de acesso

Quem pode entrar no sistema, com usuário e senha. Todos têm acesso total — não existe usuário "só leitura".

Adicionar um novo administrador exige confirmar sua senha, já que dá acesso total ao sistema para outra pessoa.

Pessoas (recebedores / corretores)

Quem recebe pagamentos e/ou atua como corretor. Não são contas de acesso — não entram no sistema nem têm senha: é uma lista de nomes reutilizável, para escolher pelos seletores "Quem recebe" e "Corretor" sem digitar toda vez.

Quem trabalha só com um proprietário pode ser amarrado à carteira dele — aí só aparece nos seletores daquela carteira. Deixe em "Todas" para quem atende o sistema inteiro (você mesmo, por exemplo).

Um contrato "vence" para reajuste 1 ano depois do último reajuste (ou do início, se nunca foi reajustado). O Dashboard avisa quando isso acontece, sugerindo um novo valor com base no percentual abaixo — o sistema não consulta nenhum índice externo real (IGP-M/IPCA) automaticamente, já que não tem acesso à internet; ajuste esse percentual manualmente conforme o índice vigente.

Percentual salvo!

Carteiras (proprietários)

Use carteiras se você administra imóveis de mais de um dono. Cada carteira representa um proprietário (ou um grupo de imóveis), e cada imóvel/contrato pode ser vinculado a uma delas. Com pelo menos uma carteira cadastrada, aparece um seletor no topo do sistema que filtra tudo (Dashboard, Contratos, Atrasos, Histórico, Despesas, Gráficos, Relatórios, Calendário) pela carteira escolhida. Se você só administra os próprios imóveis, é só não cadastrar nenhuma — o sistema continua funcionando exatamente como antes.

O proprietário e o CPF/CNPJ podem ser usados no texto do recibo pelos códigos {{proprietario}} e {{proprietario_documento}}.

Texto do recibo

Aqui você edita só o texto do recibo. Todos os dados (inquilino, imóvel, valores, datas...) são preenchidos automaticamente pelo sistema no momento em que o recibo é gerado — para isso, escreva os códigos listados ao lado no meio do texto. Onde estiver {{inquilino}}, por exemplo, sai o nome do inquilino daquele pagamento.

As quebras de linha são respeitadas exatamente como digitadas. Um código que não existir é apagado do texto final (não sai escrito no recibo).

Texto do recibo salvo!

Códigos disponíveis

Clique em qualquer código para inseri-lo no ponto onde estava o cursor (no último campo em que você clicou). A coluna da direita mostra um exemplo de como aquele código sai no recibo pronto.

Contrato antigo? Se a data de início já passou, o sistema gera automaticamente uma dívida para cada mês, do mês de início até o mês atual (útil para lançar de uma vez o histórico de um contrato antigo).

A comissão do corretor não é cobrada do inquilino (não entra no total a cobrar), mas é deduzida do total líquido — é dinheiro que vai ser pago a ele, então não fica com o proprietário. O condomínio funciona parecido: é cobrado do inquilino e depois deduzido, porque também é repassado.

O valor da caução não é somado a nenhum total — é só uma anotação informativa no contrato (o valor é, em teoria, devolvido no final).
